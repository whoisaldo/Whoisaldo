## `> ls ./projects --active`

**[EternalMonitor](https://github.com/whoisaldo/EternalMonitor)** — `v0.1.2-mirror` · [eternalmonitor.dev](https://eternalmonitor.dev)
> Use your iPad as a low-latency Windows display receiver over local-network UDP. Windows host captures via DXGI Desktop Duplication → BGRA→YUV420P → H.264 hardware encode (per-vendor auto-detect) → fragmented UDP stream. iPad reassembles, decodes via VideoToolbox, renders with Metal. mDNS/DNS-SD zero-config discovery. Ships a one-click signed installer with a virtual extended-display driver.

`Rust` `Swift` `DXGI` `VideoToolbox` `Metal` `UDP` `mDNS` `FFmpeg`

---

**[EternalRichPresence](https://github.com/whoisaldo/Eternal-Rich-Presence)** — `v1.0.0-beta`
> Discord Rich Presence bridge for Apple Music & Spotify. Live cover art via SMTC, "Listen Along" deep-link via custom `eternalrp://` URI scheme, system tray host, portable `.exe` via PyInstaller. Provider priority: Apple Music → Spotify fallback.

`Python` `pywin32` `pypresence` `COM/SMTC` `PowerShell` `catbox.moe`

---

**[Exerly Fitness](https://github.com/whoisaldo/Exerly-Fitness)** · [live demo](https://whoisaldo.github.io/Exerly-Fitness/)
> Cross-platform fitness companion with 50+ users — barcode scanning (FatSecret API), 12-step onboarding wizard (BMI/TDEE/macro targets), AI coaching via Gemini 2.0 Flash. Monorepo with a shared Express API serving both web and iOS.
>
> **iOS in active development** — SwiftUI + HealthKit sync + barcode scanning + progress photo compare mode.

`SwiftUI` `HealthKit` `React` `TypeScript` `Tailwind` `Node.js` `MongoDB` `Gemini AI` `DigitalOcean`

---

**Zero-Touch PXE Deployment** — `Philips Healthcare · NDA`
> Pitched, architected, and shipped a zero-touch PXE mass-deployment platform for a ~1,000-machine fleet backing Philips' FDA-regulated PIC iX patient monitoring infrastructure — replaced a fully manual USB imaging workflow. UEFI Secure Boot PXE chain on Microsoft-signed `bootmgfw.efi`, FOG/TFTP server on Ubuntu, PowerShell WinPE orchestrator + FastAPI service for MAC-keyed host config and live deployment status.

`PowerShell` `FastAPI` `WinPE` `UEFI Secure Boot` `PXE/TFTP` `Ubuntu`
